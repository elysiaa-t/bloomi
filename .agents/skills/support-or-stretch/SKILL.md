---
name: support-or-stretch
description: Use when building or changing how a task decides whether
  to bypass a difficulty or practice it, or the adult controls for
  that setting.
---
Each subject in a profile is set to "support" or "stretch".

Support: the tool removes the barrier so the student can show their
thinking.
- Reading: text is read aloud automatically.
- Writing: dictation is on and spelling is corrected quietly.
- Math: calculator and worked first step are available.

Stretch: the student practices the skill with help on request.
- Reading: the student reads aloud first; read-aloud is available per
  word on request.
- Writing: the student types or writes; spelling help appears as
  hints, not auto-correction.
- Math: no calculator; hints come one step at a time.

Rules:
- Only the adult view can change the setting. Show the current
  setting in the student view as a small, neutral label.
- Changing the setting never erases the session log.
- The adult report shows which mode each activity used.
