---
name: error-diagnosis
description: Use when building or changing the feature that analyzes a
  student's reading, spelling, or math mistakes and finds patterns.
  Not for generating new practice content.
---
The goal is to name the specific pattern behind mistakes, not to
count wrong answers.

- Compare each response with the expected answer and describe the
  difference precisely (for example: reads "ea" as short e; subtracts
  the smaller digit from the larger regardless of position).
- Name a pattern only when it appears at least twice. Otherwise record
  it as "seen once, watching".
- For each pattern return: subject, plain-language description, the
  examples that show it, and one suggested focus for the next session.
- Add the result to the student's session_log with the date.
- Also record what the student did well.

Wording rules:
- Describe patterns in the work, never traits of the child.
- Never state or suggest a disability diagnosis. The tool notices
  patterns for a teacher to review.
