---
name: sld-accessible-ui
description: Use when creating or changing any screen, component, or
  style in this project. Applies readability and accessibility rules
  for students with dyslexia, dysgraphia, and dyscalculia. Do not use
  for data files or prompt text.
---
Apply these rules to every screen:

Text
- Clear sans-serif font, body text at least 18px, line height 1.5 or
  more, extra space between paragraphs.
- Lines of 45 to 70 characters. Left-aligned. Never justified.
- No all-caps sentences, no long italic passages, no underlining
  except links.
- Off-white or soft background with dark text. Meet WCAG AA contrast.

Layout
- One main task per screen. One primary button per screen.
- Every icon has a text label. Every instruction is one short sentence.
- Buttons and tap targets at least 44px tall.
- Numbers in math tasks are large, well spaced, and never crowded.

Access
- Every block of student-facing text has a read-aloud button.
- Every text input has a dictation (microphone) option.
- Everything works by keyboard, with visible focus states.
- Respect reduced-motion settings. No flashing or auto-playing motion.

Never
- No countdown timers, speed scores, or leaderboards.
- No red X marks or the word "wrong". Use the student-voice skill for
  feedback wording.

After building a screen, list any rule above it does not yet meet.
