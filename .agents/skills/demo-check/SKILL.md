---
name: demo-check
description: Use when asked to review, test, or check the project
  before a demo or after a large change. Run as /demo-check or
  $demo-check.
---
Walk the demo path for each sample student: open profile, start
session, reading, writing, math, adult report.

For each screen check:
1. It loads with the sample data and shows no errors.
2. Read-aloud and dictation controls are present and respond.
3. The "Fictional sample student" label is visible where a profile
   is shown.
4. Empty, loading, and error states exist.
5. The sld-accessible-ui rules are met.
6. Student-facing text follows the student-voice rules.
7. The two students produce visibly different content.

Report a table with: screen, issue, severity (blocks demo, visible,
minor), and proposed fix. List blocking issues first. Do not fix
anything until asked.
